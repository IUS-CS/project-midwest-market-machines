### Good

* We have all the frameworks setup. We are communicating back and forth.
* Team communication was generally good - we thought the Discord integration for GitHub was very helpful.
* We enjoy our documentation system, both in GitHub and in Discord.
* We have crossed a lot of one-time-issue.

### Bad

* Some questions remain on what the backend actually is or actually does - this is uncomfortable to us.
* There were not enough code comments in the front end. Most of us were not familiar with JS.
* We need more branches. We need more PRs. Too many git issues trying to work on the same branch.
* We need a cleaner division of labor. Someone should own an issue from end to end.
* We did not always know what the other team members were working on or when - this made it hard to figure out how we were fitting in the picture.

### Actionable Commitments

* As a team, we will make more branches.
* As a team, we will more fully use time estimates on the KanBan board and share those between us.
* As a team, we will commit to using the roadmaps in the KanBan
