### Good

* We've gotten the hang of creating issues and connecting PRs to them.
* We're using a time-tracking app, which allows us to see how much work is being done on the project.
* We've gone through a few refactors for various parts of the project, meaning our code is much cleaner and well commented.

### Bad

* The developer experience for installation is tedious, which makes testing take more time and effort to do.
* Wayne wasn't added to the Github group, which made a lot of work of busy-work that didn't go towards the development of the project.
* Pull-requests with UI changes didn't always have screenshots to show what changed at a glance.

### Actionable Commitments

* As a team, we will make more of a distinction between issues for the product backlog and issues that will be completed this sprint.
* As a team, we will use the time-tracking app when working so that we can see whether or not we're on track.
* As a team, we will use illustrative software more for communicating development ideas.
