# Features

The Midwest Market Machine application will support the following core features:

- Receiving and storing funds (virtual currency)  
- Searching for and tracking assets and cryptocurrencies  
- Updating asset prices in real time  
- Simulating the purchasing of stocks based on wallet allowance  
- Tracking total investment portfolio value, including:
  - Cash breakdown
  - Asset breakdown
- Adding assets to a favorites or watchlist
- Viewing and tracking multiple assets simultaneously on a single screen
- Automated, AI-informed and safeguarded stock:
  - Watch
  - Purchase
  - Sell
  - Record lifecycle
